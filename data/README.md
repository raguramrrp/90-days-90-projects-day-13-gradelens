# GradeLens: Data Architecture & Synthetic Dataset Specifications

This directory contains the operational and demonstration datasets used by **GradeLens**.

---

## 1. Relational Entities Summary

- **Classes**: Academic cohorts (e.g. `B.Tech AI & DS - Section A`, `Section B`).
- **Students**: Student records mapped to classes and departments.
- **Faculty**: Faculty instructors linked to academic departments.
- **Subjects**: Core curriculum subjects (e.g. Data Structures & Algorithms, DBMS, Machine Learning, Operating Systems).
- **Topics**: Units, subtopics, and concepts under each subject.
- **Exams**: Internal Assessments (IA1, IA2), Diagnostic Quizzes, Model Examinations.
- **Questions**: Individual assessment questions with maximum marks, difficulty (`Easy`, `Medium`, `Hard`), and type.
- **Attempts**: Student assessment attempts with aggregate score and date.
- **Question Responses**: Granular question outcomes with marks obtained, answer status, time spent, mistake category, confidence rating, and remarks.
- **Revision Sessions**: Logged student study sessions with duration in minutes, study type, and notes.
- **Study Goals**: Milestone targets with deadlines and completion states.
- **Revision Tasks**: Daily actionable tasks with priority ratings.
- **Recommendations**: Rule-based academic guidance generated by the engine.

---

## 2. Generating Synthetic Demo Records

To re-seed or reset demonstration data:
```powershell
python -m src.data.seeder
```
Or click **Reset & Re-seed Demo Database** in the **Settings** view of GradeLens.
