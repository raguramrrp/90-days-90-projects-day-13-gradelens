# GradeLens UI Screenshots & Visual Previews

This directory contains visual captures of GradeLens in action.

## Recommended Capture Sequence:
1. `01_student_overview.png`: The main executive dashboard showing Overall Accuracy, Exam Trajectory, and Subject Mastery for student Aarav Sharma (STU101).
2. `02_topic_weakness.png`: The Topic Weakness Detection Engine view showing the "Repeated Weakness" badge on Dynamic Programming, marks loss attribution, and mistake category breakdown.
3. `03_revision_effectiveness.png`: The before-and-after comparison card showing Diya Patel's (STU102) score jump (+50%) on Gradient Descent post-revision.
4. `04_exam_bulk_import.png`: The CSV/Excel upload validation interface displaying summary metrics, valid row counts, and downloadable error reports.
5. `05_faculty_analytics.png`: The Faculty Portal displaying cohort average, grade distribution histogram, and at-risk student detection.

## How to Capture:
1. Start the app: `.\run.bat`
2. Open `http://localhost:8501` in your browser.
3. Take screenshots using `Win + Shift + S` or Chrome DevTools.
4. Save the images in this directory.
